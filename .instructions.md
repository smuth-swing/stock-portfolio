# Project Instructions for AI Coding Tools

## Project Overview
**주식 포트폴리오 관리 시스템** (Stock Portfolio Management System)

A Flask-based local server that reads Excel files from OneDrive, provides JSON APIs for a web frontend and mobile PWA, and syncs data to GitHub Pages for mobile access.

## Tech Stack
- **Backend**: Python 3.12 + Flask + openpyxl + pandas
- **Frontend**: Vanilla JS (app.js + index.html + styles.css)
- **Mobile**: Expo (React Native) PWA in `mobile/`
- **Data**: Excel files on OneDrive (`C:\Users\zerod\OneDrive\`)
- **Deployment**: GitHub Pages (`smuth-swing.github.io/stock-portfolio`)
- **External API**: LS증권 (LS Securities) API for stock data

## Critical Rules
- **NEVER modify the Excel file structure** without understanding the openpyxl rich_text handling
- **NEVER delete `.git-credentials`** or change `credential.helper=store` (background git push depends on it)
- **Always test git push** after any changes to sync logic (background processes need file-based credentials)
- **All paths are absolute** due to Task Scheduler running from System32
- **Excel file**: `C:\Users\zerod\OneDrive\주식 체크 리스트_20220328.xlsx`
- **Workdir**: `c:\Users\zerod\.antigravity\주식 포트폴리오 관리`

## Key Architecture Decisions
1. `credential.helper=store` (local) → avoids wincredman background process issue
2. `.git-credentials` at `%USERPROFILE%` → stores GitHub PAT for headless git push
3. `.git_sync.lock` → coordinates between server.py sync-receive and auto_github_uploader.py
4. `BASE_DIR = os.path.dirname(os.path.abspath(__file__))` → ensures correct CWD in Task Scheduler

## API Endpoints (server.py)

### Core Data
- `GET /api/read-excel?file=...&sheet=...` — Read Excel sheet as JSON
- `POST /api/update-row` — Update a row in Excel
- `POST /api/save-journal` — Save trade journal entry
- `POST /api/delete-row` — Delete a row
- `GET/POST /api/sync-receive` — **Mobile sync endpoint** (receives edits from mobile app)

### Sync Flow
```
Mobile App → POST /api/sync-receive → Write Excel → trigger_export_and_push_sync()
  → export_to_json.py → Copy to mobile/data/ → Git add/commit/push → GitHub Pages
```

### LS API
- `GET/POST /api/ls/config` — LS API configuration
- `POST /api/ls/fetch-trades` — Fetch trades from LS
- `POST /api/ls/import-trades` — Import trades to Excel
- `GET /api/ls/moving-averages` — Get moving averages
- `POST /api/ls/current-prices` — Get current prices

### Utilities
- `GET /api/ping` — Health check
- `GET /api/onedrive-status` — OneDrive path status
- `GET /api/target-prices` — Target price data
- `GET/POST /api/refresh-signals` — Refresh signal data

## Background Processes (Windows)
All managed by Windows Task Scheduler:
1. **Flask Server** — `run_server_hidden.vbs` — Auto-start at login
2. **Auto Uploader** — `run_auto_uploader_hidden.vbs` — Runs every 10 min
3. **Health Check** — `run_health_check_hidden.vbs` — Monitors server

## Change Documentation Rule
After EVERY code change:
1. Update `CHANGELOG.md` with date, summary, affected files, and rationale
2. If architecture changes → update `ARCHITECTURE.md`
3. If new endpoint/feature → update the API table above
4. Run `git status` to verify no unintended changes
5. Verify `git push` works (especially after credential/git config changes)
